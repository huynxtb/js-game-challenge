Albedo Injector: Aerosol Command is a turn-based console simulation game where you manage a global geoengineering project. Your goal is to lower the global temperature deviation by 2.0°C (from 2.5°C down to 0.5°C) using sulfur dioxide aerosol injections. You must balance your budget, maintain public approval, manage active balloons, and purchase aerosol stockpiles while dealing with random environmental and political events.

Setup and Run Instructions:
1. Ensure Node.js is installed on your system.
2. Save the code to a file named `albedo_injector.js`.
3. Run the game using the command: `node albedo_injector.js`
