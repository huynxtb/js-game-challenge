# Dendrochronology Bureau: Ring Sequence Operator

A gritty retro-sci-fi text simulation for Node.js. Analyze, stabilize, and sequence 5 ancient petrified Core Rings across 25 operational shifts before structural collapse or fossil rupture occurs.

### How to Run
1. Ensure you have Node.js installed (v14+ recommended).
2. Run the file directly:

node dendrochronology_bureau.js


### Objective & Rules
- Stabilize and lock 5 consecutive Core Rings within 25 shifts.
- Keep Resin Pressure strictly within 15% - 85% (instant failure at 0% or 100%).
- Regulate Sap Viscosity (ideal: 120-200 cP) to ensure scan accuracy and prevent overheating.
- Manage Power Grid reserve to operate lasers, chemical buffers, and thermal coils.
- Survive random Climate Echoes and tectonic surges.
