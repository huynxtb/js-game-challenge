Entropy Engine Protocol is a terminal-based survival strategy game. As Chief Engineer, you must balance Heat, Mechanical Stress, and Magnetic Shielding across four critical sectors to survive 20 operational cycles.

Setup:
1. Ensure Node.js is installed.
2. Save the code to a file named 'entropy_engine_protocol.js'.
3. Run the game using: node entropy_engine_protocol.js

How to Play:
- Use commands like 'vent 1', 'reinforce 2', or 'calibrate 3' to manage sector stability.
- Each action costs 1 Action Point (AP). You have 3 AP per turn.
- Type 'end' to complete your turn and progress to the next cycle.
- Prevent any sector's Heat or Stress from reaching 100%, and Shielding from dropping to 0%.
