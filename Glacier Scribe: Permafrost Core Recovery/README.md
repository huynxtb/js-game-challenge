# Glacier Scribe: Permafrost Core Recovery

An atmospheric console-based survival and resource management game written in pure Node.js.

## Premise
You are a Glacier Scribe, stationed on a rapidly deteriorating polar ice shelf. Your mission is to drill deep ice cores, reconstruct ancient atmospheric sequences, and transmit 12 complete Climate Archives to orbital science satellites before the glacier collapses into the ocean or severe freezing temperatures claim your expedition.

## Requirements
- Node.js (v14 or newer recommended)

## How to Run
1. Save the code as `glacierScribe.js`.
2. Open your terminal in the same directory.
3. Run:
   
   node glacierScribe.js
   

## How to Play
- Manage key parameters: Fuel, Crew Warmth, Drill Integrity, Spare Parts, and Glacier Integrity.
- Choose actions each cycle (Drill, Decode, Transmit, Repair, Stoke Heater, Scavenge, Stabilize).
- Solve the ice layer sequencing puzzles during decoding.
- React to random environmental hazards like blizzards, meltwater surges, and auroral anomalies.
