Marrow Weaver is a turn-based resource management console game where you control a bone marrow system to keep a host alive. Allocate Stem Cells, Iron, and Nutrients to produce Erythrocytes (Oxygen) and Leukocytes (Immune defense) while mitigating random emergency events. Survive 20 cycles without letting Oxygen drop to 0% or Pathogen Load reach 100% to win. Run the game using: node marrow_weaver.js
