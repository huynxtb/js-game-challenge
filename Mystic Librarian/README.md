Mystic Librarian is a turn-based terminal RPG written in standard Node.js. Players navigate through an enchanted library, solve ancient riddles, manage Magic Points (MP), defeat mystical guardians, collect three ancient tomes, and defeat the dark sorcerer Malakor.

Prerequisites:
- Node.js installed (version 14 or later recommended).

How to Run:
1. Save the code as `mystic_librarian.js`.
2. Open a terminal and run:
   node mystic_librarian.js

Game Rules:
- Win Condition: Collect all 3 Tomes and defeat Sorcerer Malakor.
- Loss Conditions: MP reaches 0, or suffer 3 defeats.
