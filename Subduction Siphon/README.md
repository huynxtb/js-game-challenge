Subduction Siphon is a terminal-based resource management game. You control a geothermal siphon station positioned over an active tectonic subduction zone. Your goal is to harvest 100,000 TW of energy. Balance drilling depth, core temperature, coolant levels, tectonic stress, and structural integrity to avoid catastrophic collapse.

Setup and Run:
1. Ensure Node.js is installed.
2. Save the code to a file named 'subduction_siphon.js'.
3. Run the game using: node subduction_siphon.js
